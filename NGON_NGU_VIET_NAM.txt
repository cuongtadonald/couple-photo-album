🚀 CÁCH SỬ DỤNG

1. Cài Dependencies:
   pnpm install

2. Cấu hình .env.local:
   MYSQL_HOST=localhost
   MYSQL_USER=root
   MYSQL_PASSWORD=your_password
   MYSQL_DATABASE=couple_app
   JWT_SECRET=your_secret_key

3. Khởi tạo Database:
   node scripts/init-db.js

4. Chạy Dev Server:
   pnpm dev

5. Truy cập: http://localhost:3000
